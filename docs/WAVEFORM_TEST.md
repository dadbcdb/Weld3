# WinApp 단발 PWM 시험

현재 모드는 **PID OFF 개방루프 시험**입니다. 부팅·연결·SET만으로는 PWM을
출력하지 않습니다. 기존 자동 OR PI 시험은 기본 빌드에서 실행되지 않습니다.

WinApp의 `PID 사용`, `Kp`, `Ki`, `Kd`, `목표` 입력으로 계수를 장비에 저장하고
`PID 적용`으로 전송할 수 있습니다. `GET PID`로 연결 직후 값을 읽습니다. 현재
단발 전력 시험은 PID OFF가 기본이며, 계수는 다음 폐루프 단계에서 사용할 설정으로
보관됩니다. ADC 코드는 아직 전류[A]로 보정되지 않았으므로 PID를 자동으로 전력
PWM에 연결하지 않습니다.

## 실행 순서

1. 새 `Firmware/weld3/Debug/weld3.elf`를 다운로드하고 리셋합니다.
2. `WinApp/WeldApp/PWM_SingleShot/WeldApp.exe`를 실행해 연결합니다.
3. 3단계 전류 높이와 SQ/COOL, UP, Weld Time, DOWN을 설정합니다.
4. **PWM 단발 시험 (PID OFF)**을 체크하고 **각 상 듀티 상한**을 설정합니다.
   기본값은 5%, 허용 소프트웨어 범위는 1~45%입니다. 전력부의 안전 한계라는
   의미는 아니므로 기존 SG3525 파형과 게이트 구동 조건을 기준으로 결정합니다.
5. **1회 START**를 누릅니다. 현재 화면 설정을 장비에 전송한 뒤 한 번 실행합니다.
   **STOP**으로 중단할 수 있으며, 반복 실행하려면 START를 다시 눌러야 합니다.
6. 완료 후 **PWM 시험 결과** 탭과 **시험 기록 CSV 저장**을 사용합니다.

체크하지 않은 START는 이전처럼 시간 확인만 수행합니다. 시뮬레이션 연결에서는
실제 출력이나 ADC 측정을 하지 않습니다.

## 파형의 의미

각 단계의 최대 듀티 = 듀티 상한 × 해당 단계 전류 설정 / 세 단계 중 최대 전류 설정.
예를 들어 전류 높이가 100/50/0이고 상한이 10%라면 단계별 각 상 듀티는 10/5/0%입니다.
이는 전류[A]를 듀티로 보정한 변환이 아니라 **상대적인 파형 높이**입니다.
SQ/COOL은 출력 0, UP/DOWN은 선형 변화입니다. A/B 중심 간격은 반주기입니다.

- 출력: PB7/D9=A, PD15/D6=B. 입력: PA0_C/A2, ADC1 채널 0.
- 전류 센서 보정이 없으므로 실제 전류[A]는 표시하지 않습니다.
- CSV: 시간(ms), 프로파일 목표값×1000, 각 상 명령 듀티(0.1%), ADC 평균/최소/최대.
- 듀티 그래프의 하늘색 선은 기록된 **명령값**이며 게이트 파형 실측이 아닙니다.
- 최대 2048개 기록, 프로파일 길이에 따라 1~5ms 간격입니다. 긴 프로파일에서
  짧은 세부 변화는 기록 사이에 빠질 수 있으므로 임펄스의 고속 응답은 스코프로 확인합니다.
- 종료 시 두 출력은 즉시 LOW로 전환하므로 마지막 펄스가 잘릴 수 있습니다.

## 종료 및 제한

완료, STOP, 감지된 TCP 연결 해제, TEST STATUS 수신 간격 1초 초과,
ADC 처리 3ms 초과 중단 및 기존 ADC/DMA 오류에서 출력을 정지합니다.
정상 종료/STOP 후에는 다시 시작할 수 있고, ADC 오류 래치는 리셋이 필요합니다.
기록은 다음 시험 또는 리셋 전까지만 장비 RAM에 남습니다.

CPU PAUSE 중에는 출력이 당시 레벨을 유지할 수 있습니다. **전력부를 구동하는
동안 디버거 PAUSE/한 줄 실행을 사용하지 마세요.** 소프트웨어 감시는 CPU 정지나
모든 인터럽트 차단 상태를 보호하지 않습니다. 기존 하드웨어 보호는 유지해야 합니다.

이 버전은 빌드와 호스트 테스트를 완료했지만 보드에 다운로드하거나 실제
게이트 파형·전류 응답을 검증하지 않았습니다.

## 통신

- `TEST START duty_percent=5`: 현재 장비 설정을 복사해 시험 시작. `OK TEST` 응답.
- `TEST STATUS`: 실행 ID, active, reason, 시간, 기록 개수, 명령 듀티, ADC 평균.
  활성 시험의 통신 감시도 갱신합니다. WinApp은 250ms마다 조회합니다.
- `STOP`: 시험과 시간 확인을 중단합니다.
- `TEST TRACE`: 비활성 상태에서 `TRACE id count`, CSV 레코드들, `END` 반환.
- reason: 1=완료, 2=STOP, 3=통신 정지, 4=ADC/타이밍 오류.
- `GET PID`: 현재 `kp`, `ki`, `kd`, `target`, `enabled` 반환.
- `SET PID kp=0.2 ki=15 kd=0 target=0.5 enabled=0`: PID 설정 저장.

시험 중 설정/프로파일/화면 캡처/새 START는 거절됩니다. 현재 실행 설정은 불변입니다.
